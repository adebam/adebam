## 🧩 How I Work

**From problem definition to a useful deliverable:**

1. **Understand the decision** — clarify the engineering or business question and define success metrics.
2. **Build sound pipelines** — validate data, prevent leakage, and establish meaningful baselines.
3. **Evaluate honestly** — use appropriate validation, error analysis, and uncertainty measures.
4. **Deliver usable tools** — build dashboards, APIs, and apps that make results accessible.
